## 📧 LOVEBLE AI'GA YUBORING

Assalomu alaikum!

Biz Telegram bot qilyaptibiz kahva do'konimizning sotuvlarini kuzatish uchun.

### ✅ Bot nima qiladi?
- **Real-time xabar:** Har bir sotuv bo'lganda Telegram'ga xabar (2 sekundda)
- **Kunlik hisobot:** Soat 23:00 da
- **Haftalik hisobot:** Juma soat 23:05 da
- **Oylik hisobot:** Oy boshi soat 23:10 da
- **Qoldig'i kuzatish:** Mahsulotlarning qoldig'i avtomatik yangilanadi

### 📋 Sizdan kerak:
1. **Shop ID** - Do'kon identifikatori
2. **API Key** - Bot uchun
3. **Webhook Secret** - Signature verification uchun
4. **8 Product ID** - Quyida ko'rsatilgan mahsulotlar uchun

### 📦 Mahsulotlar:
```
1. Espresso (5,000 som)
2. Cappuccino (7,000 som)
3. Latte (8,000 som)
4. Americano (6,000 som)
5. Flat White (8,500 som)
6. Macchiato (7,500 som)
7. Mocha (9,000 som)
8. Affogato (9,000 som)
```

### 🔧 O'rnatish:
**Webhook URL:** `http://MY_SERVER_IP:8443/webhook/loveble`

**Events:**
- ✅ order_paid
- ✅ order_completed

**Signature Header:** X-Loveble-Signature (HMAC-SHA256)

### 📤 Webhook Payload Format:
```json
{
  "event_type": "order_paid",
  "order_id": "ORD-20260127-001",
  "shop_id": "shop_id",
  "timestamp": "2026-01-27T14:30:45",
  "items": [
    {
      "product_id": "prod_cappuccino_id",
      "product_name": "Cappuccino",
      "quantity": 2,
      "price": 7000,
      "total_price": 14000
    }
  ],
  "total_amount": 14000,
  "payment_status": "paid",
  "payment_method": "card"
}
```
