## 💡 Key Information Quick Reference

### API Credentials to Find
```
1. LOVEBLE_API_KEY      = From Loveble → Settings → API Keys
2. LOVEBLE_SHOP_ID      = From Loveble → Settings → Shop Info
3. LOVEBLE_WEBHOOK_SECRET = From Loveble → Settings → Webhooks
4. Product IDs (8)      = From Loveble → Products → Each product
```

### Where to Put Them
```
config.py lines 11-14:
LOVEBLE_API_KEY = "..."
LOVEBLE_WEBHOOK_SECRET = "..."
LOVEBLE_SHOP_ID = "..."

config.py PRODUCTS section:
"product_name": { "loveble_id": "..." }
```

### Webhook URL to Set
```
http://YOUR_SERVER_IP:8443/webhook/loveble
```

### How Bot Works
```
1. Sale happens in Loveble POS
2. Loveble sends webhook to bot
3. Bot verifies signature (security)
4. Bot saves sale to database
5. Bot sends Telegram notification to admin
6. Done! (all within 2 seconds)
```

### At 23:00 Every Day
```
Bot automatically sends:
- Daily sales summary
- Products sold and quantities
- Revenue total
- Current stock levels
- Low stock alerts
- Timestamp
```
