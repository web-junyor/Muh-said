# DEPLOYMENT CHECKLIST

## Pre-Deployment

- [ ] Python 3.9+ installed
- [ ] All dependencies installed: `pip install -r requirements.txt`
- [ ] `.env` file created with all required variables
- [ ] `data/receipts/` directory created
- [ ] Telegram bot token obtained from @BotFather
- [ ] Click API credentials configured
- [ ] Admin token generated (use: `python -c "import secrets; print(secrets.token_urlsafe(32))"`)

## Configuration Verification

- [ ] BOT_TOKEN is valid (bot responds to /start)
- [ ] CHAT_ID is set (test with `python -c "from aiogram import Bot; import asyncio; asyncio.run(Bot('YOUR_TOKEN').get_me())"`)
- [ ] CLICK_SECRET_KEY matches Click API configuration
- [ ] ADMIN_TOKEN is strong and random (min 32 chars)

## System Testing

- [ ] Start server: `python -m backend.main`
- [ ] Server runs without errors on startup
- [ ] Verify `/admin/today?token=YOUR_TOKEN` returns valid JSON
- [ ] Send test payment to webhook (verify signature is accepted)
- [ ] Confirm Telegram notification received in chat
- [ ] Verify PDF receipt file created in `data/receipts/`
- [ ] Test idempotency: retry same webhook (returns duplicate status)

## Scheduler Verification

- [ ] Set system time to 22:59, wait 90 seconds
- [ ] Confirm daily report sent to Telegram at 23:00
- [ ] Check format includes product breakdown and total
- [ ] Verify no double-sends on next minute

## Production Setup

- [ ] Server accessible from Click payment gateway
- [ ] Firewall allows inbound TCP 8000
- [ ] HTTPS/SSL certificate installed (if using reverse proxy)
- [ ] Nginx/Apache reverse proxy configured (optional but recommended)
- [ ] Process manager running (systemd, supervisor, or PM2)
- [ ] Log rotation configured
- [ ] Backup strategy defined

## Monitoring Setup

- [ ] Error logging configured
- [ ] Disk space monitoring for `data/` directory
- [ ] CPU/memory monitoring on server
- [ ] Uptime monitoring active
- [ ] Telegram notifications for critical errors

## Security Hardening

- [ ] `.env` file permissions set to 600 (owner read/write only)
- [ ] `/data/` directory permissions set to 750
- [ ] No sensitive data in git repository (.gitignore checked)
- [ ] Secrets manager considered for key rotation
- [ ] CORS configured appropriately (if needed)

## Final Checks

- [ ] All test sales processed correctly
- [ ] Statistics accurate in `/admin/today` endpoint
- [ ] No errors in logs during 1-hour test period
- [ ] Daily report sent at 23:00 correctly
- [ ] PDF receipts high quality and readable
- [ ] QR codes in receipts scan correctly

4. Restart server
